## Исправления этого прохода

| Область | Подтверждённая проблема и результат |
| --- | --- |
| Загрузки и хранение | Старые callbacks не вмешиваются в новую попытку; завершившийся без данных источник и ошибки копирования больше не оставляют владельцев диапазонов ждать; размер частичного чтения соответствует доступным байтам. |
| Повторы загрузки | Пустой первый ответ раньше обнулял счётчик ошибок и повторялся бесконечно; теперь действует ограничение повторов. FetchManager различает попытки, а не только id ресурса. |
| Метаданные кэша | Повреждённые `.meta` с переполнением, отрицательными или пересекающимися интервалами отвергаются; формат и проверка CRC сохранены. |
| Стикеры и реакции | Убран цикл повторного декодирования уже готового кадра; скрытая/остановленная анимация не возобновляется из запоздавшего callback; корректно обрабатываются неизвестное число кадров видео, пустой Lottie и замена источника. |
| Display link | Частота пересчитывается после удаления владельца; остановленный последний владелец не удерживает таймер; изменение подписчиков из callback безопасно. |
| Потоковое видео HLS | Отмена XHR, замена запроса и закрытие плеера отменяют загрузку сегмента. Старый ответ не попадает в новый запрос; временный файл освобождается и при отброшенном событии. Ответ из фонового чтения передаётся JS bridge на main queue. |
| Фон | Действующая задача переиспользуется. Старое expiration не закрывает новую задачу; исчерпанный бюджет не создаёт цикл мгновенных expiration. Отказ UIKit `.invalid` преобразуется в `nil`, после исчерпания бюджета новые Postbox-транзакции не разрешаются одним старым allow-window. |
| Фоновая загрузка | Без сети она не удерживает тихое аудио сама по себе, очередь сохраняется. Переключатели применяются без нового события загрузки, Low Power/подключение зарядки пересчитывают политику. При остановке аудио даётся короткое окно для завершения транзакции. |
| Локальная речь | Offline Only включён по умолчанию и мигрируется; установленная модель используется и для коротких записей. Отмена не перезапускает распознавание, частичный текст не объявляется финальным по ошибке Apple. |
| Локальный перевод | Явный локальный режим не подменяется серверным. Опросы и расшифровки используют тот же локальный путь; очередь ограничена, есть отмена и таймаут, неполный результат не кэшируется как успешный. |
| Определение языка и конвертация | Корректные UTF-16 интервалы для emoji/пересечений; распознаватель языка отдельный для каждого потока. Отмена зависшего writer освобождает незавершённый файл, промежуточные объекты декодера освобождаются по мере обработки. |
| Клиентские функции | Снят найденный оставшийся локальный замок с Premium/PremiumTurbo/PremiumBlack иконок. Настройки Swiftgram, локальные перевод/расшифровка и десять аккаунтов не требуют клиентской подписки. Настоящий серверный Premium-статус не подменяется. |
| Идентификаторы контактов | Три парсера принимали положительный Int64 за пределами 56-битного формата PeerId. Теперь URL, ссылки контактов и Siri отвергают значения выше `0x00ffffffffffffff`; старое assertion воспроизведено в отдельном subprocess, без открытия вредной ссылки на телефоне. |

[Apple SystemLanguageModel](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel).

Apple Speech и Translation работают локально только для поддерживаемых моделей/языков. Translation может запросить скачивание языковой модели. Гарантий «никогда не нагревается», «нет ни одного бага» и «всё загружается мгновенно» этот проход не даёт.
