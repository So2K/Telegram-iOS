# SuperGram Stability Plan

## Источники

- Telegram iOS: https://github.com/TelegramMessenger/Telegram-iOS/issues
- Swiftgram: https://github.com/Swiftgram/Telegram-iOS/issues

## Порядок разбора

1. Проверять новые и недавно обновлённые issues перед каждым релизом.
2. Сначала разбирать падения, чёрный экран, потерю push-уведомлений и повреждение локальной базы.
3. Затем разбирать нагрев, расход батареи, зависания при открытии чатов и медиа.
4. После этого разбирать ошибки плеера, жестов, навигации и визуальные дефекты.
5. Переносить патч только после воспроизведения проблемы на текущей ветке или подтверждения причины по коду.

## Проверка исправления

- Зафиксировать точные шаги воспроизведения и ожидаемое поведение.
- Добавить узкий тест там, где компонент поддерживает автоматические тесты.
- Выполнить Release build и Xcode Analyze.
- Запустить SwiftLint для изменённых Swift-файлов и `git diff --check`.
- Установить IPA поверх существующей версии и проверить сохранность локальной базы.
- Быстро переключать чаты, поиск, настройки и медиапросмотр на устройстве.
- Сверить системные crash-логи до и после теста.
- Для push отдельно проверить реальное входящее сообщение при свёрнутом и принудительно закрытом приложении.

## Текущий контрольный список

- Исправлено зацикливание декодирования повреждённого GIF/видео без кадров (Telegram-iOS #2246).
- Добавлена локальная расшифровка голосовых сообщений через Apple Speech без Telegram Premium.
- Усилена блокировка случайного горизонтального переключения при почти вертикальном жесте.
- Production APNs entitlement включён; реальную доставку нужно подтверждать отдельным входящим сообщением.
- Отслеживать сообщения о задержках уведомлений и повышенном расходе батареи в обоих трекерах.
